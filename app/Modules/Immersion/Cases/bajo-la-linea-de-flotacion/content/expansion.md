# Expansión: el aislamiento como hecho central

Se abren los interrogatorios. Hay seis sospechosos, dos testigos y una fuente secundaria: el
sistema de control del buque.

El registro de puertas estancas confirma el hecho central: la sección inferior quedó cerrada
a las 22:15 y se reabrió para toda la tripulación a las 22:45. Durante esa ventana, solo
personal autorizado pudo entrar.
